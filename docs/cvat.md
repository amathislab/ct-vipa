# CVAT

## Setting up a local cvat instance
* CVAT installed locally - see [instructions](https://docs.cvat.ai/docs/administration/basics/installation/)
* Data mounted as a docker volume - see [instructions](https://docs.cvat.ai/docs/administration/basics/installation/#share-path)
* Set up SSH port forwarding (e.g., ssh user@host -L 8080:localhost:8080)
* Ask admin to get username and password for CVAT local server
* Log in on Google Chrome: go to http://localhost:8080/ and enter newly created credentials.

## Projects
We create two CVAT projects:
1. Tracks correction: This is to correct tracking errors

Raw annotation constructor:
```
[
  {
    "name": "Animal",
    "id": 1,
    "color": "#fa3253",
    "type": "rectangle",
    "attributes": []
  }
]
```

2. Tracklet annotations: This is to annotate tracklets for individual level attributes

Raw annotation constructor: generated by Step 10 (`prepare_tracklets_for_cvat_annotation`) as `cvat_label_constructor.json` in the project folder.
It contains the `Species`, `Activity`, `Action` and `Action2` attributes, with the classes defined in the `labels` section of the config (see [docs/config.md](config.md#labels)).
Additional attributes can be added manually in CVAT: they are kept as is in the final annotations.

Unfortunately, it is not convenient in CVAT to perform both operations together.
CVAT interpolates information between keyframes, which makes individual level attributes annotation on animal-centered videos very efficient as one only needs to annotate behavior switches. 
When we perform track correction, every frame is considered as a key frame. Otherwise the bounding boxes would automatically get interpolated even if a corresponding localization exists in the xml file. As such, one would need to annotate every frame for the individual-level attributes. 

## Uploading and downloading annotations
We provide two bash scripts to exchange XML files with the CVAT server instance using the [CVAT CLI](https://docs.cvat.ai/docs/api_sdk/cli/):
* `create_cvat_tasks.sh`: For each video in a given folder, creates a new annotation task given a pre-generated XML file and uploads this annotation to the CVAT database.

```bash
bash create_cvat_tasks.sh <input_video_folder> <input_xml_folder> <project_path> <cvat_project_id> <credentials> <cvat_org>
```

`<credentials>` are in the form of `username:password`.

We use this script to create tasks for both track corrections, and for tracklet annotations.  
The `<cvat_project_id>` can be found on the CVAT server. It is required so that the tasks are automatically associated to the correct project.  
The `<project_path>` corresponds to the root of the mounted data volume. It is necessary to match a given annotation XML file to the video in the CVAT data volume.

* `export_cvat_annotations.sh`: For each CVAT task in a given project ID, downloads the annotation as a XML file **for tasks in validation status**. Task in any other status will not be downloaded.

```bash
bash export_cvat_annotations.sh <input_xml_folder> <output_xml_folder> <cvat_project_id> <credentials> 
```

The `<input_xml_folder>` is required to properly match annotation filenames.  
We use this script to download task annotations for both track corrections, and for tracklet annotations.
